（二）产品介绍

一款给职场开会的人、听网课/播客的学习者用的、在实时会议与音视频回放场景下、解决「记不全细节、纪要写得慢」的工作学习 AI 助手（音视频转写 + 智能纪要）。
  • 已确认官网口号「万语千言 · 心领神悟」；能力表述含实时语音转文字、多语言同步翻译、区分发言人、章节速览/待办/发言总结等。tingwu.aliyun.com
  • 已确认首页三条主入口：开启实时记录、上传音视频、播客链接转写。
  • 已确认侧栏信息架构：首页 / 我的记录 / 收藏 / 分享 / 发现 / 回收站 / 帮助与反馈；另有企业 API、低代码模板入口。
  • 待确认核实帮助中心有「如何在手机上使用」文章；产品动态历史写过「网站及微信小程序」。本次未验证小程序现网能力是否与网页对等。

（七）待核实二次验证清单

  • V1 登录后完整走一遍「实时记录」：确认点、停录、失败提示、是否扣/退时长。→ 影响用户层异常四条、技术层确认点。
  • V2 实测上传一条短音频：导出格式、局部重生成、说话人改名。→ 影响交付与「不满意」异常。
  • V3 打开「如何在手机上使用」与微信小程序，核对是否与网页能力一致。→ 影响形态描述。
  • V4 C 端是否存在人民币订阅/加油包价目（不仅赠时长）。→ 影响模型层成本。
  • V5 C 端实际调用的模型名是否在设置/关于里暴露。→ 影响模型清单「已确认」级别。
  • V6 失败退时长、存储上限政策原文。→ 影响异常与基础层。
