AI 产品拆解

面向 Cursor / Grok Bot 的可复用 Skill：用五问五层拆解 AI 产品，输出飞书 / Markdown / HTML。

仓库文件

  • SKILL.md — Skill 正文（复制到 Agent 的 workflows 即可用）
  • 通义听悟拆解示例（HTML 报告）

怎么用

  1. 把本仓库的 SKILL.md 放进 Agent 的 Skill / workflows 目录。
  2. 对助手说：「按 AI 产品拆解 Skill 拆 XXX」，并指定输出形态（飞书 / Markdown / HTML）。
  3. 先确认产品形态（网页 / App / 其他），再取证；结论标「已确认 / 待确认核实」，文末附二次验证清单。
